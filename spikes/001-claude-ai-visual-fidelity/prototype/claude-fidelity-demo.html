I examined the authentication service in Nostos.Frontend/src/app/auth/. We can isolate the BFF OIDC callback handling cleanly using an interceptor.

Proposed Architecture

Here is what the streamlined flow will look like:

  • Delegate session state refresh to the HTTP interceptor without freezing the UI thread.
  • Route token expiry events through AuthSignalService.
auth-interceptor.ts Copy 
export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const auth = inject(AuthService);
  return next(req).pipe(
    catchError((err) => {
      if (err.status === 401) {
        auth.handleSessionExpired();
      }
      return throwError(() => err);
    })
  );
};
